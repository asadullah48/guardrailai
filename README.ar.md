# GuardrailAI: طبقة مسارات العمل القطعية

> **حواجز حماية قبل التنفيذ وبعده، وتوجيه للبدائل عند المخالفات، وسجل تدقيق بسلسلة تجزئة SHA-256 تكشف التعديل.**

يفصل المشروع بين فحص السياسات والمعالجة والتدقيق باستخدام طلبات مكتوبة الأنواع وواجهة FastAPI واستوديو تفاعلي بالعربية والإنجليزية.

## المزايا الهندسية

- توجيه مخالفات `BLOCKING` و`CRITICAL` إلى الاستجابة البديلة قبل المعالجة وبعدها.
- مراجع ثابتة للمعاملات والتصعيد باستخدام SHA-256، مع اختبارات عبر عمليات Python مستقلة.
- تغطية حقول كل كتلة بالتجزئة، بما فيها كتلة البداية والتوقيت والبيانات الوصفية، والتحقق من ترتيب الكتل وروابطها.
- أمثلة سياسات مالية وصحية وقانونية، مع اختبارات لمسارات النجاح والفشل وواجهات API.

## الحدود / خارج النطاق

القواعد أمثلة تعتمد على حدود وقائمة حظر ثابتة وأنماط نصية؛ لا تقدم اعتماداً تنظيمياً أو فحص OFAC حياً أو تغطية HIPAA كاملة أو تحققاً طبياً وقانونياً. المعالجة محاكاة محلية. البديل الآمن يحجب العملية ويعرض الإرشادات؛ التصعيد يعيد مرجعاً وحالة انتظار دون نظام موافقات خارجي. خيار `REDACTION` يرفض الطلب ولا ينفذ تنقيحاً آلياً.

السجل في الذاكرة وقابل للتعديل، ويضيع عند إعادة التشغيل ويستبدل عند تكرار معرّف المسار. كشف إعادة كتابة السلسلة كاملة أو حذف نهايتها يحتاج نقطة تحقق موثوقة خارجية. ختم التدقيق غير موقع وليس شهادة عدم إنكار. التوقيت والأختام تختلف بين التشغيلات. البوابة التجريبية لا تتضمن مصادقة أو عزلاً للمستأجرين أو تخزيناً دائماً، ولم يختبر النشر الإنتاجي في هذه المراجعة. ملف SPEC.md مقترح تصميم تاريخي.
